<h2 id="introduction">🌟 Introduction</h2>

This repository implements the **jump search** algorithm in C#, with unit tests and BenchmarkDotNet benchmarks.

<h2 id="installation">📦 Installation</h2>

1. Clone or download the project.
    ```bash
    git clone https://github.com/lncodes/algorithm-search-jump.git
    ```

2. Open `c#/src/Jump.sln` in Visual Studio or Rider.

> Targets .NET Core 3.1; install that SDK, or retarget the project to a current .NET version.

<h2 id="usage">🧑‍💻 Usage</h2>

- Build:
    ```bash
    dotnet build "c#/src/Jump.sln"
    ```

- Run the unit tests:
    ```bash
    dotnet test "c#/test"
    ```

- Run the benchmarks (Release mode):
    ```bash
    dotnet run -c Release --project "c#/benchmark"
    ```
